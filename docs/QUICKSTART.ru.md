# Запуск — русский

[English](QUICKSTART.en.md) · [README](../README.md)

## Требования

- Windows x64.
- .NET 10 SDK: команда `dotnet --list-sdks` должна показывать версию `10.*`.
- CS2 со сборкой движка **14186**, **14188** или **14189** для основного режима. Другие сборки намеренно отклоняются.
- Git для клонирования. Вместо него можно скачать ZIP ветки `main` на GitHub и распаковать.

## Скачать и собрать

Открой PowerShell:

```powershell
git clone --branch main https://github.com/UsefullSoftwareOrNot/DiversantCS2.git
cd DiversantCS2
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build.ps1
```

Скрипт восстанавливает зависимости, запускает тесты и собирает приложение в `artifacts/CameraProbe/`. Готовых DLL в репозитории нет: сначала нужна сборка. Во время повторной сборки закрой работающий CameraProbe через **Ctrl+C**, чтобы освободить DLL.

## Запустить

1. Запусти CS2 и включи консоль разработчика. Оставь её на стандартной клавише **`~ / Ё`**.
2. Открой **`Start-ConVars.cmd`** из корня проекта. `Start-CameraProbe.cmd` запускает тот же основной режим; достаточно одного окна.
3. Для переключения команд во время freeze time нажми **F6**, играя за T/CT. Сначала закрой чат, консоль и меню. Пока программа вводит команды, не нажимай другие клавиши.
4. Для штатного завершения нажми **Ctrl+C в окне CameraProbe** и дождись завершения восстановления.

PowerShell-вариант запуска:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Run.ps1 -EnableSwitching
```

## Клавиши и поведение

| Клавиша | Действие |
| --- | --- |
| F6 | Всегда применить и проверить команды изображения. Во время freeze time за T/CT дополнительно сменить команду туда и обратно и повторно применить изображение. |
| F7 | Записать состояние камеры на 8 секунд. |
| F8 | Отменить текущую запись или последовательность переключения. |
| Ctrl+C в окне программы | Завершить программу и выполнить восстановление сохранённых изменений. |

F6 использует `spec_freeze_time 1000` и `mat_fullbright 1`. Конфиг `camera_probe` не требуется.

Восстановление камеры включается автоматически для распознанного состояния бага. При HP=0, активном восстановлении камеры и вне freeze time основной режим экспериментально устанавливает **локальный HP=10000**. Отдельный `Test-Movement.cmd` и пробел для этого не нужны.

Это не меняет здоровье на сервере. Восстановление серверного движения **не подтверждено**. Игра может перезаписать локальное здоровье. При смене контекста программа проверяет возможность восстановления и сохраняет журнал, если результат неоднозначен. Числовые значения двух ConVar при выходе автоматически не возвращаются к прежним значениям.

## Диагностика и обновление

- Журналы основного режима: `artifacts/CameraProbe/captures/`.
- Один снимок состояния: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Run.ps1 -Snapshot`.
- Если DLL занята, закрой старое окно CameraProbe через Ctrl+C. CS2 закрывать не требуется.
- Если подготовлено обновление в `artifacts/CameraProbe.update/`, следующий запуск основного `.cmd` установит его.
- Если сборка игры не поддерживается, не меняй номер в схеме вручную: смещения и проверки машинного кода требуют отдельной проверки.
- Для обычного обновления из Git: закрой CameraProbe, выполни `git pull --ff-only`, затем повтори команду сборки.
